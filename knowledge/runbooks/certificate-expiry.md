# 手順書: TLS 証明書の期限切れ

対象サービス: auth-service, web-frontend（独自ドメインを持つサービス全般）
重要度の目安: ログインやトップページが表示できなければ SEV1

## 症状
- ブラウザに「この接続ではプライバシーが保護されません」などの証明書エラーが出る
- API クライアントが `certificate has expired` で接続に失敗する

## 確認すること
1. 証明書の有効期限
   ```bash
   echo | openssl s_client -connect example.com:443 -servername example.com 2>/dev/null \
     | openssl x509 -noout -dates
   ```
2. 証明書がどこに紐づいているか（ロードバランサー / CDN / API の独自ドメイン）
3. ACM の証明書なら、DNS 検証用のレコードが消えていないか（消えていると自動更新されない）

## 対処
1. ACM で発行した証明書: DNS 検証レコードを戻し、更新されるのを待つ
2. 外部で購入した証明書: 新しい証明書をインポートし、紐づけ先を差し替える
3. CDN に紐づく証明書は、リージョン（us-east-1）を間違えないこと

## 再発防止
- 期限の 30 日前・7 日前に通知が来るように監視を設定する
- 可能な限り ACM の自動更新に寄せる
